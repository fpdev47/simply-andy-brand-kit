# Simply Andy — Brand Kit

Brand kit final de Simply Andy (@__simplyandy): paleta Cuaderno + Terracota, tipografía Big Shoulders (títulos) / Manrope (texto).

## Contenido

- `index.html` — el brand kit completo en una sola página: paleta, roles de color, tipografía, resaltados y combinaciones, contraste, mockups en acción, reglas de uso.

## Uso

Abrir `index.html` en cualquier navegador. No requiere build ni dependencias — es una página autocontenida (HTML + CSS + JS inline, fuentes vía Google Fonts).
